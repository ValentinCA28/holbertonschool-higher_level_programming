> Repository regroupant l'ensemble des projets de programmation de haut niveau du cursus Holberton School : Python, JavaScript, SQL, Flask et API REST.

---

## Objectifs d'apprentissage

- Maitriser les fondamentaux et les concepts avances de Python (classes, heritage, serialisation, ORM)
- Comprendre et manipuler les bases de donnees relationnelles avec SQL et SQLAlchemy
- Developper des applications web cote serveur avec Flask et Jinja2
- Construire et securiser des API RESTful
- Maitriser JavaScript cote client (DOM, Fetch API) et cote serveur (Node.js)
- Appliquer les bonnes pratiques : TDD, gestion d'exceptions, POO, design patterns
